# Evaluation Engine

Evaluation engine for policy, heuristic, and LLM grading.

## What This Provides

- Evaluation runners
- Scoring engines
- Evaluation type definitions

## Inputs

- Evaluation specs
- Run inputs

## Outputs

- Scores
- Evaluation logs

## Dependencies

- Internal: core utils
- External: LLM providers (if enabled)

## Standalone Notes

Portable if copied with `packages/core/eval` and its engine deps.
