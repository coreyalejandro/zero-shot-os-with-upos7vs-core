# Governance API

Fastify API surface for governance checks and integrations.

## What This Provides

- HTTP API endpoints
- Governance routing
- Health and readiness checks

## Inputs

- HTTP requests
- Config and policy data

## Outputs

- JSON responses
- Audit logs

## Dependencies

- Internal: packages/core
- External: fastify and related deps

## Standalone Notes

Portable if copied with `packages/api` and configured env vars.
